# NLP/LLM 26 周科研入门学习计划

## 项目定位

这套计划面向零基础大一学生的半年科研入门路线，主题聚焦自然语言处理（NLP）与大语言模型（LLM）。默认节奏为 26 周，每周 8-12 小时自学。

整套计划以学习为主，实践辅助。每周有基础任务、标准任务和拓展任务。基础薄弱的学生先把最低要求做扎实，基础好的学生再做拓展，不需要所有人跑同样大的模型。

## 26 周结束后，希望学生能做到什么

1. 能用 Python、pandas、scikit-learn 和 PyTorch 完成简单 NLP 实验。
2. 能解释文本分类、词表示、RNN、Attention、Transformer、BERT、GPT、RAG 等核心概念。
3. 能使用 Hugging Face 完成 tokenizer 分析、模型推理和一次小规模微调。
4. 能读懂论文的摘要、引言、方法图和主实验表，知道论文在解决什么问题。
5. 能做一个 baseline，设置一个简单对比，保存结果并分析错误样例。
6. 能完成一个范围较小的科研项目，并做 5–8 分钟汇报。

## 每周怎么学

每周建议投入 6–10 小时，可以分 3–4 天完成，不要求按天打卡。

建议顺序：

1. 先看本周 README，知道这周学什么。
2. 选 1–2 个主要资源学习，不要同时收藏十几个教程。
3. 跑通最小代码例子。
4. 完成基础或标准实践。
5. 整理周报、论文笔记、结果和问题。

每周通常有三档任务：

- **基础实践**：基础较弱的学生必须完成。
- **标准实践**：正常进度建议完成。
- **拓展实践**：有余力再做，不影响主线。

## 每周交什么

通常包括：

1. 一页周报；
2. 一个代码或 notebook；
3. 一份结果、图表或错误样例记录；
4. 3 个本周问题；
5. 需要读论文的周，再交一份论文笔记。

模板放在 `templates/` 中。不要为了填模板写空话，重点记录自己实际做了什么、哪里没看懂、代码哪里出错。

## 论文怎么读

前期不要求从头到尾精读，也不要求看懂所有公式。先回答：

- 论文解决什么问题？
- 输入和输出是什么？
- 方法大概怎么做？
- 和什么 baseline 比？
- 主实验结果说明什么？
- 作者有没有提到局限？

通常两周安排一篇重点论文。只读 README 中指定的部分即可。

## 关于数学

需要的数学会放到对应内容里：

- 文本分类时学向量、矩阵、均值和指标；
- 词表示时学点积和余弦相似度；
- PyTorch 训练时学梯度和梯度下降；
- Attention 时学矩阵乘法和 softmax；
- 做实验时学均值、方差和随机种子。

数学基础好的学生可以看拓展资源，基础弱的学生先做到“能解释、会使用”。

## 关于算力

- Week 03–15 的大部分任务可以在普通电脑上完成。
- Week 16 的小规模微调可以使用 Colab、Kaggle 或租赁 GPU。
- 不要求训练大模型。
- LoRA、量化和较大模型只作为拓展内容。
- 使用在线 API 时要记录模型名称、参数、调用次数和费用，不要上传隐私数据。

## 关于 AI 工具

可以使用 ChatGPT等工具帮助理解概念、检查报错和修改表达，但必须：

- 自己运行并检查生成的代码；
- 能解释交上来的内容；
- 核对论文、数据、模型和引用；
- 在周报中说明 AI 帮了什么；
- 不直接提交自己看不懂的答案。
