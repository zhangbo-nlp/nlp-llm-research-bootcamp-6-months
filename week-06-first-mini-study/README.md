# Week 06 第一阶段小实验：文本分类与词表示

## 本周定位

本周不再增加很多新概念，而是把 Week 03–05 学到的内容整理成一个小而完整的实验。

学生需要体验一次最基本的科研过程：提出一个小问题、选一个 baseline、只改变一个因素、看结果、分析错误、做简短汇报。

题目一定要小。宁可只比较两种文本表示，也不要同时换数据、换模型、换指标。

## 本周学习主线

1. 如何把一个想法写成可回答的小问题。
2. 如何选择 baseline。
3. 如何保证对比公平。
4. 如何记录实验设置和结果。
5. 如何分析成功和失败样例。
6. 如何写 2–3 页短报告并做 5 分钟汇报。

## 建议学习内容

### 研究问题

研究问题要能用当前数据和一周时间回答。不要只问“哪种方法最好”，而要写清“在什么数据上，比较什么，用什么指标”。

### 公平对比

- 两个方法使用同一份 train/dev/test。
- 主要指标保持一致。
- 一次只改变一个因素。
- 结果不好也要保留。

### 错误分析

先看具体文本，再归纳错误类型。不要先写一套空的分类表，再强行把所有样例塞进去。

## 可选问题

从下面选一个即可：

### 方向 A：word n-gram 与 character n-gram

问题示例：

```text
在同一份中文短文本分类数据上，character n-gram 是否比 word n-gram 更稳定？
```

### 方向 B：TF-IDF 与平均词向量

问题示例：

```text
在同一份数据上，平均词向量是否能修正 TF-IDF 对同义表达的错误？
```

### 方向 C：数据量对 baseline 的影响

问题示例：

```text
训练数据从 100% 减少到 30% 后，TF-IDF 分类结果会如何变化？
```

### 方向 D：简单预处理是否有用

问题示例：

```text
去停用词或保留否定词，对分类的 F1 有什么影响？
```

## 本周实践

### 基础实践

- 写清一个研究问题。
- 保留 Week 04 的 TF-IDF baseline。
- 增加一个对比方法。
- 使用同一份数据划分。
- 输出 accuracy 和 macro-F1。
- 找 5 个失败样例。

### 标准实践

在基础实践上补充：

- 运行 2–3 次不同随机种子，或说明为什么没有随机性。
- 建立一张结果表。
- 分析至少 10 个错误样例。
- 找 3 个“新方法修正 baseline”的例子。
- 找 3 个“新方法反而做错”的例子。
- 写 2–3 页短报告。

### 拓展实践

任选一个：

- 请同学按 README 复现你的结果。
- 增加一个小型挑战集，专门测试否定、同义改写或短文本。
- 让两个人独立给错误样例分类，比较是否一致。

## 短报告结构

1. 题目和研究问题。
2. 数据。
3. baseline 和对比方法。
4. 实验设置。
5. 结果表。
6. 错误样例。
7. 结论和局限。

## 本周最低要求

- 一个清楚的小问题。
- 一个 baseline 和一个对比。
- 一个结果表。
- 5 个错误样例。
- 5 分钟口头汇报。

## 本周标准交付

- 一页周报。
- 小实验代码或 notebook。
- 实验记录。
- 2–3 页短报告。
- 8 页以内或 5 分钟汇报材料。
- 3 个本周问题。

## 导师检查点

- 问题是否足够小？
- 两个方法是否使用同一份数据？
- 对比是否只改变一个主要因素？
- 指标是否能回答问题？
- 错误分析是否包含具体文本？
- 学生能否说明结果支持什么、不支持什么？
