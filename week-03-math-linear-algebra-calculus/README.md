# Week 03 数据分析、必要数学与机器学习入门

## 本周定位

前两周已经学过 Python 数据结构和文件读写。本周开始接触真正的实验数据，同时补一点后面马上会用到的数学。

本周不要求学完整本线性代数，也不要求推复杂公式。只需要学会看数据表、看数组 shape、理解向量和矩阵，并知道一个机器学习任务里的样本、特征和标签是什么。

如果基础较弱，本周把一份文本 CSV 读进来，完成统计和画图，就算合格。

## 本周学习主线

1. pandas 数据表：读取、查看、筛选、统计和保存。
2. 文本数据：样本、字段、标签、类别分布和文本长度。
3. 必要数学：标量、向量、矩阵、shape、均值、中位数和方差直觉。
4. 机器学习任务：输入、特征、标签、模型、预测。
5. 数据质量：空值、重复、乱码、过短文本和可能错标的数据。

## 建议学习内容

### pandas 与文本数据

需要掌握：

- `pd.read_csv()` 读取数据。
- `head()`、`shape`、`columns` 查看数据。
- `value_counts()` 统计类别。
- 用字符串长度统计文本长短。
- 用 `isna()`、`duplicated()` 检查空值和重复。
- 用 Matplotlib 画简单柱状图和直方图。

### 够用的数学

先理解含义，不追求证明：

- 标量是一个数，向量是一列数，矩阵是一张二维数字表。
- shape 表示每个维度有多大。
- 文本经过表示以后，通常会变成向量或矩阵。
- 均值表示平均水平，中位数更不容易被极端值影响。
- 方差可以帮助我们判断数据是否很分散。

### 机器学习基本词汇

用一个文本分类任务理解：

```text
一条评论 -> 一条样本
评论文字 -> 输入
正面/负面 -> 标签
文字转成的数字 -> 特征
根据特征预测标签 -> 模型
```

## 本周实践

### 基础实践

使用第 2 周的数据，或导师提供的一份 100–1000 条文本数据：

- 读取 CSV。
- 打印数据量和列名。
- 统计每个类别有多少条。
- 统计文本长度的最小值、平均值、中位数和最大值。
- 检查空文本和完全重复文本。
- 每个类别随机看 5 条样本。

### 标准实践

在基础实践上继续完成：

- 画类别分布柱状图。
- 画文本长度直方图。
- 找出 5 条最长和 5 条最短文本。
- 写一段 300–500 字的数据说明：数据来自哪里、标签是什么意思、有哪些明显问题。
- 用 NumPy 创建一个向量、一个矩阵，并写出每个 shape 的含义。

### 拓展实践

任选一个：

- 比较不同类别的文本长度。
- 写一个 `check_data(df)` 函数，自动检查空值和重复 ID。
- 用 5 个二维向量练习点积，先不要求理解余弦相似度。
